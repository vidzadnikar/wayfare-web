    Works with Claude.

    Wayfare Studio is fully compatible with Claude. For the edit itself, we recommend our vlog skill — it guides Claude through every step, from the first cut to the publishing package.

    # in Claude Code, no Node.js needed:

    /plugin marketplace add vidzadnikar/wayfare-skills

    /plugin install wayfare@wayfare

    # then:

    Make a vlog from my Lisbon clips.

    npx skills add vidzadnikar/wayfare-skills --skill vlog -g -a claude-code

    # then, in Claude Code:

    Make a vlog from my Lisbon clips.

    Needs Claude Code. The npx route also needs Node.js.
