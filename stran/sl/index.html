Vsi vlogi

Kje smo bili.

Vsak kraj, kjer je nastal vlog. KlikniTapni ga, pa se spodaj pokažejo vlogi od tam.

Zavrti z vlečenjem. Približaj z gumboma, s ščipom ali s ⌘/Ctrl + koleščkom. Klik na kraj te pripelje k njemu.Zavrti s prstom, približaj s ščipom ali z gumboma. Tapni kraj in pokažejo se filmi od tam.

    Claude je vgrajen.

    Odpri ploščo Claude ob časovnici, poveži svojo naročnino Claude (prek Claude Code na računalniku) ali ključ API pri Anthropicu in povej, kaj želiš. Claude ureja z orodji aplikacije, ti vidiš vsak korak in ga vrneš s ⌘Z.

    Uporabljaš Claude Code? Tam deluje naš skill vlog:

    # v Claude Code, brez Node.js:

    /plugin marketplace add vidzadnikar/wayfare-skills

    /plugin install wayfare@wayfare

    # nato:

    Naredi vlog iz mojih posnetkov iz Lizbone.

    npx skills add vidzadnikar/wayfare-skills --skill vlog -g -a claude-code

    # nato v Claude Code:

    Naredi vlog iz mojih posnetkov iz Lizbone.

    Potrebuješ Claude Code. Pot z npx potrebuje še Node.js.

    Pogosta vprašanja.

    Ali je Wayfare res zastonj?

    Aplikacija je: vse funkcije so brezplačne, brez naročnine in brez omejitev. Samodejno montažo naredi Claude, za to pa rabiš svojo naročnino Claude (Pro ali Max) ali ključ API pri Anthropicu, kjer plačaš le, kar porabiš. Brez Clauda urejaš sam na časovnici.

    Kje so moji posnetki?

    Na tvojem računalniku. Nič se ne naloži, dokler sam ne objaviš.

    Ali moram znati montirati?

    Ne. Claude zloži dan v zgodbo, ti pa z enim stavkom poveš, kaj želiš drugače. Kdor želi, lahko vse ureja tudi sam na časovnici.

    Kaj potrebujem za Claude?

    Naročnino Claude (Pro ali Max) in Claude Code na računalniku: plošča odpre Anthropicov namestilnik, prijaviš se pri Anthropicu. Ali ključ API pri Anthropicu, kjer plačaš le, kar porabiš.

    Na katerih napravah deluje?

    Na Macih z Apple silicon (macOS 12 ali novejši), na 64-bitnem Windows 10 ali novejšem in na Androidu 8 ali novejšem. Različice za Linux še ni.

    Zakaj me Mac ob prvem zagonu opozori?

    Aplikacija še ni notarizirana pri Applu. V Sistemskih nastavitvah odpri Zasebnost in varnost, na dnu klikni »Vseeno odpri« in potrdi. Od takrat se odpira normalno.

    Kako povem, kaj popraviti?

    Uporabi obrazec za odziv ali v aplikaciji odpri meni ⋯ in izberi Pošlji odziv. Vsako sporočilo pride do tistega, ki dela Wayfare Studio.

    Tvoje naslednje potovanje, zmontirano.

    Različica 0.2.0 je zastonj, brez naročnine. Za montažo s Claudom rabiš svoj Claude. Posnetki ostanejo na tvojem računalniku, dokler ne objaviš.

    Namestitev z ukazom (za napredne)

    Če poznaš Terminal ali PowerShell, lahko Wayfare Studio namestiš z enim ukazom. Ukaz prenese isti paket z GitHuba, preveri njegovo kontrolno vsoto in aplikacijo namesti.

    Mac, v Terminalu:

    curl -fsSL https://wayfarestudio.pages.dev/install.sh | bash

    Windows, v PowerShellu:

    irm https://wayfarestudio.pages.dev/install.ps1 | iex

    Android, s telefonom:

    Kodo poskeniraj s kamero telefona in odpri povezavo: aplikacija se prenese naravnost na telefon. Android enkrat vpraša, ali dovoliš namestitev iz brskalnika.

    Dodaj v Obtainium: namesti Wayfare z GitHuba in ga sam posodablja (najprej namesti Obtainium).

    Raje govoriš kot tipkaš? Spoznaj Sayfare.

    Narekovanje, ki zna slovensko, za Mac, Windows in Android. Pritisneš bližnjico, govoriš, besedilo je tam, kjer pišeš.
